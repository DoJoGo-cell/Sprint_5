# qa_python_5 - Тестирование Stellar Burgers

Автоматизированные тесты для сайта [Стеллар Бургерс](https://stellarburgers.education-services.ru/).
Проект покрывает следующие функциональности:
- Регистрация
- Авторизация
- Переход в личный кабинет
- Переход из личного кабинета в конструктор 
- Выход из аккаунта
- Раздел «Конструктор»

## Реализованные тесты (12 тестов):

### 1. Тесты Регистрации
- `test_registration_valid_values_successful` — проверка регистрации с помощью ввода сгенерированных валидных данных
- `test_registration_invalid_password_unsuccessful`— проверка появления ошибки при попытке ввода невалидного пароля при регистрации

### 2. Тесты Авторизации
- `test_authorization_button_on_main_page` — проверка перехода на страницу авторизации нажатием на кнопку Войти на главной странице
- `test_authorization_button_personal_account` — проверка перехода на страницу авторизации нажатием на кнопку Личный кабинет на главной странице
- `test_authorization_button_on_registration_page` — проверка перехода на страницу авторизации нажатием на кнопку Войти на странице регистрации
- `test_authorization_button_password_recovery` — проверка перехода на страницу авторизации нажатием на кнопку Войти на странице восстановления пароля

### 3. Тест Перехода в личный кабинет
- `test_transition_to_personal_account_from_main_page` — проверка перехода на страницу личного кабинета нажатием на кнопку Личный кабинет на главной странице 

### 4. Тест Перехода из личного кабинета в конструктор 
- `test_transition_to_construction_from_personal_account_page` — проверка перехода в раздел конструктор на главной странице нажатием на кнопку Конструктор на странице личного кабинета 

### 5. Тест Выхода из аккаунта
- `test_log_out_account` — проверка выхода из авторизованного аккаунта нажатием на кнопку Выйти на странице личного кабинета

### 6. Тест Раздела «Конструктор»
- `test_construction_transition_to_buns_section` — проверка перехода в секцию Булки в разделе конструктор на главной странице
- `test_construction_transition_to_sauces_section` — проверка перехода в секцию Соусы в разделе конструктор на главной странице
- `test_construction_transition_to_toppings_section` — проверка перехода в секцию Начинки в разделе конструктор на главной странице

## Зависимости
selenium
pytest

## Запуск тестов
pytest -v tests/
